# Players

Reusable character assets for ChennaiRun, shared by area scenes.

| Folder | Character | Format | Animation |
|---|---|---|---|
| [`Baymax/`](Baymax/) | Inflatable Baymax model | `.glb` | Separate poseable parts; no skeleton or clips |
| [`Vikram/`](Vikram/) | Vikram | `.fbx` | Mixamo humanoid skeleton; locomotion clips not supplied |

In the Chromepet Unity project, **Chrompet > Sync Area Assets** copies both player files into `Assets/Characters/`. See each folder's README for setup.
