# buildings
OSM footprints extruded to estimated heights (type-based guesses; OSM has almost no height data here). Local metres, X=east, Z=north, Y=up, origin 12.9487 N 80.1394 E.

## v2
`campus_buildings.glb`: 60 OSM campus footprints styled per video notes (Admin blue glass + portico + Kalam statue, LHC pale yellow-green with sunshades, light-green dept blocks, red/yellow Aero with portico, Rajam Hall white/orange, hostels pink/purple, pale-yellow/blue, green/pink, Hangar I rusty pitched-roof shed, Hangar II vaulted roof, etc.), 3.5 m storeys, flat roofs. Names with "(approx)" were assigned heuristically to untagged footprints; see `../data/v2_meta.json`.
`outside_buildings.glb`: 8,732 OSM footprints, 2-6 storeys (1-3 near the station), pastel walls, parapets, shop awnings near the station.
